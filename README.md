# 📊 AdventureWorks Sales & Customer Analytics Dashboard

An interactive **Power BI** dashboard built on the AdventureWorks dataset, analyzing sales, products and customers.

## 📌 Key KPIs
| Metric | Value |
|---|---|
| 💰 Total Revenue | **$109.8M** |
| 🛒 Total Orders | **31K** |
| 👥 Total Customers | **19K** |
| 📦 Units Sold | **275K** |

## 💡 Key Insights
- 🇺🇸 The US generates **57% of total sales**
- 🚵 **Mountain Bikes** are the most profitable category ($4.9M)
- 📅 Revenue peaks in **March** and **October**
- 🔁 **Over 99% of customers** are returning buyers

## 🖥️ Report Pages
Home • Sales Overview • Product & SalesPerson • Customer Analytics

## 🛠️ Tools Used
Power BI • Power Query • DAX • Data Modeling

Download `Dhiru adventure works.pbix` and open it in Power BI Desktop (free).
